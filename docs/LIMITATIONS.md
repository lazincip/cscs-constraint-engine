# Known Limitations (`v2026.10.x`)

Published, not hidden. Each limitation is stated with its measured evidence and its open benchmark track.

1. **Cold-Start Subspace Calibration ($N < 10$) & Held-Out Track A Baseline:** When initialized with only 4 seed prompts (`S1–S4` cold start), the learned SVD subspace $V_k$ spans a narrow hyperplane. On the held-out Track A control battery (`Linux VM, Python 3.12.3, numpy 2.5.4`), held-out in-domain median residual is $A = 0.9607$ vs. paraphrase $B = 0.9461$, near-neighbor technical $C = 0.9829$, and far-OOD $D = 0.9763$ (separation margin $D - A = 0.0156 \approx 0.02$, failing the $\ge 0.10$ separation target and $A < C < D$ ordering; `v2026.10.0` similarly scored $A = 0.9267, C = 0.9629, D = 0.9614$, margin $0.0347$). Additionally, short valid questions ($< 3$ words) are blocked by the quality gate (`F1–F3`), and held-out in-domain query `A4` is blocked at 4-seed cold start. Production deployments should seed `SpectralManifold.learn()` with $\ge 10$ representative domain sentences during warm-up; calibrating cold-start separation is an open benchmark track (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
2. **Cross-Platform BLAS/LAPACK Floating-Point Variance:** While `SpectralManifold` enforces deterministic sign canonicalization on right-singular vectors (matching cross-machine friction to $\le 0.005$ on 3 of 4 demo turns), minor floating-point variations across CPU architectures and BLAS backends can shift intermediate SVD coordinates when singular values are near-degenerate (e.g., `0.009` residual difference on Turn 2). Cross-environment benchmarks should evaluate **relative within-run ordering** rather than raw cross-machine scalar equality.
3. **Lexical Hash Representation & Keyword-Salad Gaming:** Signed 3-gram and word-unigram feature hashing provides zero-GPU speed ($< 0.1\text{ ms}$) and morphological sensitivity, but does not capture deep synonymy between lexically disjoint phrases without prior co-occurrence, and can be gamed by domain keyword salad (`E1` scored the lowest residual in the Track A battery: `0.8216` in `v2026.10.1`, `0.7623` in `v2026.10.0`).
